# SVG skeleton for a registered diagram

Copy, replace the shapes and labels, keep the rules. The site inlines the file
(after removing anything executable) inside a zoomable figure whose label is
the registry `alt`; Obsidian embeds the same file with `![[<id>-<slug>.svg]]`.

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 720 300" role="img" aria-labelledby="t d">
  <title id="t">Raft write path, end to end</title>
  <desc id="d">A client sends a write to the leader. The leader replicates it to two followers. After one acknowledges, a majority of three stores the entry, so the leader commits and replies.</desc>
  <defs>
    <marker id="arrow" viewBox="0 0 10 10" refX="9" refY="5" markerWidth="7" markerHeight="7" orient="auto-start-reverse">
      <path d="M0 0 L10 5 L0 10 z" fill="currentColor"/>
    </marker>
  </defs>
  <g fill="none" stroke="currentColor" stroke-width="2" color="#8a887f">
    <path d="M120 150 H228" marker-end="url(#arrow)"/>
  </g>
  <g font-family="system-ui, sans-serif" font-size="16" text-anchor="middle">
    <rect x="20" y="120" width="100" height="60" rx="30" fill="none" stroke="#2a78d6" stroke-width="2"/>
    <text x="70" y="155">Client</text>
  </g>
</svg>
```

Rules (the gate checks the first five):

1. `viewBox` and no fixed `width`/`height`, so it scales to 375 px.
2. `<title>` (and `<desc>` with the conclusion).
3. Real `<text>` labels, not paths that look like letters.
4. No `<script>`, no `on…=` attributes, no `<foreignObject>`.
5. No external `href`/`xlink:href` to `http(s)`.
6. Fills `none` or very light; strokes `currentColor`, `#8a887f` (neutral) or
   the accent `#2a78d6`; text inherits the page colour, so it reads in light and
   dark themes.
7. 3–7 boxes; labels of one to three words; font size 13–18 in a 720-wide box.
8. Dashed lines for replies or optional paths; say so in `explanation`.
9. Under 300 KB; hand-written or generated by code, never traced bitmaps.
