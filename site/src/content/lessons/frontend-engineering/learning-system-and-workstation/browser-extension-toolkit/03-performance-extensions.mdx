Your app feels fast on your laptop. Users still report a slow checkout. Both can be true, because you measure one load on one machine.

Two kinds of slowness need two kinds of tool. A wasted render is a component render that changes nothing on the screen. The React DevTools Profiler finds them: it records each commit and shows which components rendered and how long each took. Page-level speed is a different question. Core Web Vitals are three page metrics. LCP (Largest Contentful Paint) is the time until the largest content appears. CLS (Cumulative Layout Shift) measures how much the layout jumps. INP (Interaction to Next Paint) is the delay between an interaction and the next frame.

The Chrome DevTools Performance panel shows these three metrics live while you use the page. That is lab data: your device, your network, your clicks. INP appears only after you interact with the page. The same panel can also show field data from CrUX, the Chrome User Experience Report, which collects the metrics from real Chrome users. Compare the two before you decide what to fix.

**Note.** CrUX shows only that real users are slow. It does not name the component. Use the Profiler for that step.
