You ship a release page. Is it usable for a person who cannot see the screen, or who uses only a keyboard? A manual review of every element is slow.

An accessibility extension runs rules against the page DOM and lists the elements that break them. Many of these tools use axe-core, an open-source rule engine. Teams run them on each release, because a check takes seconds.

Take color contrast. The contrast ratio compares the brightness of text with the brightness of its background. WCAG 2.2 level AA asks for 4.5:1 for normal text and 3:1 for large text.

axe-core has three results, not two. A check can pass, fail as a violation, or return "incomplete". Incomplete means the machine cannot decide.

{/* <!-- concept: headings-and-landmarks --> */}

Structure is the second check. Headings must nest by rank: an `h2` follows an `h1`, and you do not skip from `h2` to `h4`. Landmarks are page regions that a screen reader user can jump to. The elements `header`, `nav`, `main`, `aside` and `footer` mark them. When a page has several `nav` regions, give each one a label. WAVE from WebAIM is on the W3C list of evaluation tools. Extensions such as HeadingsMap also show the outline.

In the lab, change the text color, the background and the heading levels. Predict which rules fail before you look.

<Experience id="a11y-checks-lab" />

**Note.** Automated checks find only some problems. No rule can tell you whether a keyboard user reaches every control in a sensible order, or whether a screen reader announces the page well. Test those by hand on every release.

<Depth level="internals">
axe-core computes contrast the way the browser paints. It walks the stack of elements under the text, blends the layers from the bottom up, and includes text shadow and opacity. Then it rounds the ratio down, so 4.499:1 never shows as a pass, because WCAG allows no rounding up. A background image, an overlap, a one-character text or an empty field becomes incomplete, not a failure. See `lib/checks/color/color-contrast-evaluate.js:120-154 @ e80f6b7` and `lib/core/base/rule.js:272-287 @ e80f6b7` in the axe-core repository.
</Depth>
