Your button is blue, but your CSS says green. Your editor shows the file you wrote. It cannot show which matching rule the browser applied. The Elements panel can: it is the DevTools view of the live DOM, the tree of objects the browser built from your HTML.

Every page of this lesson follows one loop: inspect, debug, measure, fix, verify.

Select the button in the Elements panel. The Styles pane lists every CSS rule that matches it. The cascade is the CSS algorithm that picks one winning declaration for each property. Predict its result before you look.

Follow one property in the diagram, from the matching rules to the box model.

<Diagram id="styles-to-computed" />

The Styles pane answers "why": it keeps the losing declarations. The Computed pane answers "what": it shows only applied values, and its box model diagram shows margin, border, padding and content size. Edit a value in Styles and the page changes at once, so you test a fix without a rebuild. The cost: a reload discards the edit, so copy the fix back to your source file.

Two tools catch states that are hard to see. Click the `flex` or `grid` badge next to a container to draw an overlay of its items or tracks on the page. Click `:hov` and force `:hover` or `:focus`, so the rule stays applied while your mouse is in DevTools.

**Note.** A crossed-out declaration is not a bug by itself. The bug is usually which rule won.

<Depth level="internals">

When a stylesheet uses `@layer`, the Styles pane shows the cascade layer of each rule. A cascade layer is a named group of rules that the cascade ranks as a group, before it compares selectors. So a simple selector in a later layer can beat a more specific selector in an earlier layer. Read the layer name above the rule before you raise specificity.

</Depth>

<Depth level="production">

The grid overlay has viewing options: line labels, track sizes, area names and extended lines. Firefox has a similar grid overlay and a flexbox inspector that explains each item's final size, so use it when a flex item has a size you cannot explain. Forced states also fail silently in one way: if you forget to clear `:hover`, the page keeps the forced style while you test other things.

</Depth>
