A card grid looks right in Chrome. In Safari one column collapses. Chrome DevTools cannot show that bug, because Chrome does not have it. Firefox DevTools and Safari Web Inspector are the two you add to Chrome.

In Firefox, an element with `display: grid` gets a grid icon. Click it, and Firefox paints the grid lines over the page. The flexbox inspector lists each flex item with its Content Size, Flexibility and Final Size. That tells you why an item shrank.

Firefox has two more tools. Responsive Design Mode (Cmd+Opt+M on macOS) sets the page to a device size or preset. Use it instead of the Chrome device toolbar when a layout breaks only in Firefox. It simulates screen size, pixel density and touch, so it does not replace a real phone. The Style Editor shows every stylesheet of the page. Use it to edit a whole sheet, not one rule. Save writes a local copy, not your source file.

Safari Web Inspector is hidden by default. On a Mac, open Safari Settings, then Advanced, and turn on "Show features for web developers". A Develop menu appears. Web Inspector then gives you Elements, Network, Sources and Timelines for WebKit, the engine of Safari.

The cost is three toolsets, and each shows only its own engine. The Firefox accessibility inspector shows the Gecko tree, not the view of the operating system.

<Depth level="internals">

The Fonts tab lists the fonts the selected element uses, an editor, and every font on the page. A static font gets size, line height, weight and italic controls. A variable font gets one control per axis and a dropdown of named instances. Note one trap: `font-variation-settings` overrides `font-weight`, whatever the cascade order says.
