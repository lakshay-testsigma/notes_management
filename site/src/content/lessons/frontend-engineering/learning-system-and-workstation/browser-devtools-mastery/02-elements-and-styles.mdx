Your "Buy" button is wider than the design. Right-click it and choose Inspect. The Elements panel selects the element in the DOM tree, and the Styles tab lists every CSS rule that matches it. The cascade is the browser's way to choose one value when several rules set the same property. In the Styles tab, a declaration that lost is crossed out.

Two rules set padding here: `.btn { padding: 8px 16px }` and `.btn-primary { padding: 12px 24px }`. The button is 80 px of text with a 1 px border.

**Assumption.** The numbers use the default box sizing, where width is content plus padding plus border.

The Styles tab shows every rule, so you see why a value won. The Computed tab shows only the final values, so you read the result quickly. The box model diagram shows margin, border, padding and content, and you can double-click a value to change it. These edits change only the page in memory, not your files. This loop is faster than edit, save and reload.

<Depth level="internals">

Some states exist only while you act. A `:hover` style vanishes when the mouse moves to DevTools. Click `:hov` in the Styles tab and check `:hover`, `:focus` or `:active` to force that state. Elements with `display: grid` or `flex` get a badge in the DOM tree. Click it to draw a layout overlay on the page. Elements with `container-type` get a container badge. The Styles tab also groups rules by cascade layer. Firefox's Flexbox inspector shows an item's content size, flexibility and final size.

</Depth>

<Depth level="production">

To keep a CSS change across page loads, use Local Overrides or save it to a workspace. Otherwise, right-click a declaration and choose "Copy all CSS changes", then paste them into your source.

</Depth>
