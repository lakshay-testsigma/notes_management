A click handler runs twice. The usual fix is to add `console.log` to your code, rebuild and click again. The Console is faster: it runs JavaScript against the live page, so you ask the page directly. Console utilities are extra functions that DevTools adds to the Console, such as `$0` and `getEventListeners()`.

Each arrow in the diagram goes from the prompt to the part of the page that one utility reads.

<Diagram id="console-utilities-map" />

`$0` is the element you selected in the Elements panel, and `$1` to `$4` are the ones before it. `$$()` returns a real array of elements that match a CSS selector, so `.length` and `.map()` work at once. `getEventListeners($0)` lists the listeners on the selected element. Two `click` entries answer the double-click question. `copy()` puts any value on your clipboard.

A live expression is an expression pinned to the top of the Console. DevTools re-runs it almost continuously, so you watch `document.activeElement` change while you press Tab.

The trade-off: these utilities exist only in the Console, so a fix you find still goes into your source file.

When you do log from code, pick the `console.*` method that fits the job. `console.table()` shows an array of objects as a table. `console.assert()` logs an error only when its condition is false.

**Note.** The Console runs in one context, chosen in its context menu. If the button is inside an iframe and the top frame is selected, `$$()` returns an empty array.

<Depth level="production">

Turn on Preserve log in the Console settings when a bug happens during navigation. Without it, the Console clears its messages on each page load. Eager evaluation shows the result of an expression while you type it. Keep live expressions cheap: DevTools runs each one again and again, so a heavy query can slow the page you are measuring.

</Depth>

<Depth level="internals" title="Beyond console.log">

`console.group(label)` and `console.groupEnd()` fold related messages under one label. `console.time(label)` and `console.timeEnd(label)` print the elapsed time between two points, enough for a quick duration check. `console.trace()` prints the stack trace, so you see which function called this one. Failure mode: these calls are easy to forget in production code. They fill the Console of every user and can expose data, so remove them before you merge.

</Depth>
