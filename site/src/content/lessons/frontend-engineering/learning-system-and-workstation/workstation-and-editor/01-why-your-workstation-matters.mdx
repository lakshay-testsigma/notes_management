Two developers face the same new laptop. The one with a **dotfiles repository** is done before lunch. A dotfile is a configuration file whose name begins with a dot, such as `.zshrc` for the shell and `.gitconfig` for Git.

An **install script** links those files into place with symlinks, so every new machine gets the same shell, git identity, editor settings, and Node version. The repository is under version control, so a broken change is undone with `git checkout`, and a fresh machine is `git clone` plus one script.

The alternative is a team where everyone has slightly different tools, and a bug that shows up on one machine never reproduces on another.
