Some visitors use a browser that lacks the API your code calls, so the page can break. **Feature detection** is a small test that asks "can this browser do X?" and then runs enhanced code or fallback code. The MDN guide rejects the old shortcut, browser sniffing (guessing support from the browser's name), because a name does not tell you what works.

In JavaScript, `"geolocation" in navigator` checks that the member exists. In CSS, `@supports (grid-template-columns: subgrid)` applies its rules only when the browser supports them. In the guide's geolocation example, the `else` branch shows a static map, so every visitor gets a working page.

A **polyfill** is code that adds a missing feature to an older browser. Load one only when a browser you target lacks the feature. **Browserslist** is one shared config that lists your target browsers. Autoprefixer, Babel preset-env, postcss-preset-env and eslint-plugin-compat all read it, so you write the list once and every tool agrees. The cost is extra code, and risk: a polyfill from a third-party server runs with full power on your page.

An **origin trial** lets your site use an experimental Chrome feature with real users for a limited time. The trial ends, so put the feature behind a detection test too.

**Note.** The guide says some features are undetectable, and suggests a polyfill for them. Test channels, core-js and progressive enhancement come in a later topic.

<Depth level="internals" title="How an origin trial works">

The Chrome docs ("How it works") give the steps. First, register your origin for the trial. Then Chrome gives you a token. Add the token to your pages with a meta tag, an HTTP header, or JavaScript. The trial has an end date. To keep using the feature, you give feedback and renew. When the trial ends, the feature stops working on your site, and your fallback branch runs.

</Depth>

<Depth level="production" title="The polyfill.io attack">

Many sites loaded polyfills from the shared address cdn.polyfill.io. In February 2024 a new owner bought the domain. Sansec reported on 25 June 2024 that the script now injected malware, and that more than 100,000 sites loaded it. Cloudflare then rewrote links to the domain, and Namecheap put the domain on hold. **Interpretation.** A polyfill is code you trust with your whole page, so know who serves it.

</Depth>
