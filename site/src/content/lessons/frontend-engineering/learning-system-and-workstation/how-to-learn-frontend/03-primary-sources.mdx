A tutorial, an MDN guide, and a specification all describe the same feature. When they disagree, only one of them is the ground truth.

Read the diagram bottom-up. Each arrow moves one step closer to the source.

The specification says how a technology must work. Three standards bodies write the main ones: WHATWG owns the HTML Living Standard, TC39 and ECMA own ECMAScript, and W3C owns CSS. MDN, Mozilla's web documentation, explains how to use a spec and keeps its guides current. A tutorial is a third-hand summary, and it ages as the platform moves.

A new feature reaches a spec the long way. Someone writes an explainer with a code demo, a working group discusses it, and only then does the text enter the spec.
