You want to use CSS Nesting in a form. Checking which of six browser versions support it on **caniuse** is slow, and the answer changes every month.

Trace a new feature down the decision path: does every core browser ship it, and have 30 months passed?

<Diagram id="baseline-ship-decision" />

**Baseline** gives every web platform feature one of three labels. A feature stays at **Limited availability** until every browser in the **core browser set** — Chrome, Edge, Firefox, and Safari — ships it. When all four do, it becomes **Newly available**, which means the browsers now agree on how it behaves. After 30 months it becomes **Widely available**. **caniuse** lists the same support feature by feature and browser version, while Baseline turns it into one label you can decide with. CSS Nesting became Newly available in August 2023, so it reaches Widely available in February 2026.

**Note.** Newly available is already a guarantee: every core browser supports the feature, so shipping it is safe even before the 30 months pass.
