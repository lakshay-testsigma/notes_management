You want to use CSS Nesting in a form. Checking which of six browser versions support it on **caniuse** is slow, and the answer changes every month.

Trace a new feature down the decision path: does every core browser ship it, and have 30 months passed?

<Diagram id="baseline-ship-decision" />

**Baseline** gives every web platform feature one of three labels. A feature stays at **Limited availability** until every browser in the **core browser set** — Chrome, Edge, Firefox, and Safari — ships it. When all four do, it becomes **Newly available**, meaning they agree on how it behaves; after 30 months it becomes **Widely available**. A **caniuse** table shows the detail behind that label: the per-version support grid and usage data. CSS Nesting became Newly available in August 2023, so it reaches Widely available in February 2026.

A **Baseline target** is the named year or level a team ships against, such as **Baseline 2025**. Safe to ship is relative to the target, not absolute: a feature inside it is safe, one outside it still needs a decision.

**Note.** Newly available is already a guarantee: every core browser supports it, so shipping is safe even before the 30 months pass.

Ship a feature while it is still Limited, and the browsers that have not shipped it drop it. If the feature is load-bearing, those visitors get a broken page, and the team fields bug reports from one browser while the others look fine.
