A shoe shop cut its return window from 30 days to 14 days last week. Its support bot is a **language model**: a program that continues text one small piece at a time, using only what was in its training data and what is in the prompt it receives. The training data ended months ago and never contained this shop's policy.

The model was the same in both runs. Only the prompt changed. In the first run the application searched the shop's documents, kept the two **chunks** (short pieces of a document) that fit the question best, and pasted them into the prompt next to the question. This pattern is **retrieval-augmented generation**, RAG for short: retrieve first, then generate from the retrieved text.

It repairs the two weak points that the paper which introduced RAG names for a model on its own: its knowledge is hard to update, and it cannot show where an answer came from. Here the policy lives in a file the shop can edit, and the answer points to the chunk it used.
