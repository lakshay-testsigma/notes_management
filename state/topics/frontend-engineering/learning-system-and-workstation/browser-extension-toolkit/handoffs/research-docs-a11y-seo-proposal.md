# Proposal: docs-a11y-seo

Sources added (all tier A, verified 2026-11-18): google-js-seo-basics-docs (digest, lesson), google-redirects-docs, w3c-wai-selecting-evaluation-tools, w3c-wcag22-understanding-contrast-minimum. Existing: dequelabs-axe-core-repo.

## Concepts
- automated-a11y-rule-limits. prereq: accessibility-extensions. Sources: w3c-wai-selecting-evaluation-tools, section "What Evaluation Tools Can Do and Can Not Do" ("Tools cannot check all accessibility aspects automatically"; human judgement is required). Also Accessibility Insights overview (microsoft; not added) lists ~50 automated checks plus ~20 manual tests in Assessment. Practical: run an extension, then do the manual tab-stop check. Failure: treating a zero-issue scan as compliant.
- accessibility-extensions. prereq: none. Sources: dequelabs-axe-core-repo (engine behind axe extension, Lighthouse, Accessibility Insights); WAI tools page "Features of Evaluation Tools". Aliases: a11y checkers. WAVE and Silktide: not verified in this unit.
- contrast-and-vision-checks. prereq: accessibility-extensions. Source: w3c-wcag22-understanding-contrast-minimum, sections "Success Criterion", "Notes on formula", "Tools"-related Related Resources: 4.5:1 normal text, 3:1 large text (18pt or 14pt bold), level AA, values not rounded (4.499:1 fails), measure from CSS colour not anti-aliased pixels. Names Colour Contrast Analyser. Chrome vision-emulation page not verified (open question).
- headings-and-landmarks. Not covered by a verified source here. Open question: add W3C WAI tutorials (Page Structure) in another unit.
- seo-extensions. prereq: rendered-vs-source-html. Source: google-js-seo-basics-docs "Describe your page with unique titles and snippets", "Set the canonical URL", "Use robots meta tags carefully". Extension tool pages (Detailed SEO, Ahrefs) unverified.
- rendered-vs-source-html. prereq: none. Source: google-js-seo-basics-docs "How Google processes JavaScript" (crawling, rendering, indexing; Google indexes rendered HTML) and "Follow best practices for web components" (check rendered HTML with URL Inspection). Practical: compare View Source with DOM in DevTools. Failure: content injected late or blocked never seen.
- redirects-and-structured-data. prereq: rendered-vs-source-html. Sources: google-redirects-docs ("Overview of redirect types", "Server-side redirects", "meta refresh", "JavaScript location redirects"): permanent shows target, temporary shows source; instant meta refresh = permanent; JS redirect is last resort. google-js-seo-basics-docs "Use meaningful HTTP status codes" (soft 404) and "Use structured data" (JSON-LD may be generated by JS; test it). Verified but not added (slot cap): https://developers.google.com/search/docs/appearance/structured-data/intro-structured-data, sections "Supported formats" (JSON-LD recommended, Microdata, RDFa) and "Get started" (Rich Results Test, URL Inspection).
