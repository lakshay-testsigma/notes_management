# Dependabot

Dependabot is a GitHub feature that opens pull requests when a dependency has a new
version. It can watch npm packages and GitHub Actions on separate schedules, and it can
ignore small version bumps. Zustand uses it for daily npm updates and weekly action
updates, and it ignores patch and minor releases.
