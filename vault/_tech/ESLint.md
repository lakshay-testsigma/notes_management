# ESLint

ESLint checks JavaScript and TypeScript code against a set of rules. It can run with
type information, so a rule can know the type of a value. Zustand uses ESLint with
typescript-eslint and the React, testing-library and Vitest plugins, and it keeps the
test-only rules in a separate block for the `tests/**` folder.
