# Node.js

Node.js runs JavaScript outside the browser, on a server or in a build script. It gives
JavaScript a file system, a network stack and a module system, and it also has a `vm`
module that runs code in a separate realm. Zustand uses Node for its build scripts and
for one test that creates a promise in another realm.
