# TypeScript

TypeScript is JavaScript with a type checker added on top. The checker runs before the
code ships and can prove that a store, a middleware and a selector agree on their shape.
Zustand is written in strict TypeScript, and its middleware contract is enforced by the
type system rather than by a runtime check.
