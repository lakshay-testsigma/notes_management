# GitHub Actions

GitHub Actions is the continuous integration system built into GitHub: a repository
holds YAML workflow files that GitHub runs on a push, on a pull request, or on a
schedule. Zustand uses eight workflows for testing, version matrices, bundle size,
publishing and documentation.
