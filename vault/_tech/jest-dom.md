# jest-dom

jest-dom adds the DOM assertions that a test framework does not ship: `toBeInTheDocument`,
`toHaveTextContent` and similar matchers. It loads them as extra expect matchers, so a
test reads like a statement about the page. Zustand loads it once in the setup file for
the whole suite.
