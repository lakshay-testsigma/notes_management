# Redux DevTools

Redux DevTools is a browser extension that shows a list of actions and lets a developer
jump back to an earlier state. A library talks to it through the extension object on
`window`, and it sends its own actions and receives time-travel commands back. Zustand
connects to the extension only in development builds.
