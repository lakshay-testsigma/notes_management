# Set-Cookie attributes

Set-Cookie attributes are the extra settings after name=value in a Set-Cookie header: Domain, Path, Max-Age, Expires, Secure, HttpOnly, SameSite, Partitioned and Priority. Each one changes where, how long, or how a browser sends the cookie.
