# Local versus global install

The two places a command-line tool can live: global, installed once for the whole machine and reachable from any directory, or local, installed into one project's dependencies. A local install is recorded in the project's manifest, so a teammate who clones the repository gets the same tool version with one install command; a global install is not recorded anywhere.
