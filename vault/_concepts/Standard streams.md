# Standard streams

The three text channels every command-line program gets: standard input (STDIN), standard output (STDOUT) and standard error. A program reads STDIN by default, prints results to STDOUT and prints errors to STDERR, and a pipe connects one program's STDOUT to the next program's STDIN.
