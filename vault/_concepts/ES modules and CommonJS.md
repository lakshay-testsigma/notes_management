# ES modules and CommonJS

ES modules (ESM) and CommonJS (CJS) are the two ways a JavaScript file can load other files in Node.js. ESM uses `import` and `export`; CommonJS uses `require()` and `module.exports`. Node.js decides which one a file uses from its extension and from the `type` field in the nearest `package.json`.
