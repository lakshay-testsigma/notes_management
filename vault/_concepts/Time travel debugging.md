# Time travel debugging

<!-- tutor:placeholder -->
Time travel debugging means recording every change to a program's state as a named
step, so a developer can look at the history, jump back to an earlier state, and watch
what happens next. The recorded steps are the same ones the application performed, and
restoring an old state does not add a new step to the history.
