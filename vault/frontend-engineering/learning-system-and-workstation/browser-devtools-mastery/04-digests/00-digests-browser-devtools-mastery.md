# Digests for Browser DevTools mastery (used in every phase)

These are the sources worth reading in full one day, each reduced to a ten-minute note. Read
them in this order.

1. [[chrome-devtools-network-reference-browser-devtools-mastery|Chrome DevTools Network features reference]] — it defines the Network panel and splits each request into timing phases; read it first.
2. [[chrome-devtools-performance-reference-browser-devtools-mastery|Chrome DevTools Performance features reference]] — it defines traces, the flame chart and long tasks over 50 ms that later lessons rely on.
3. [[ecma-426-source-map-browser-devtools-mastery|ECMA-426 Source map format]] — the standard behind debugging minified code: JSON maps, Base64 VLQ mappings and how a tool finds the map.
4. [[firefox-devtools-user-docs-browser-devtools-mastery|Firefox DevTools user docs]] — the second engine: Grid, Flexbox, font and accessibility inspectors, and phone debugging with about:debugging.
