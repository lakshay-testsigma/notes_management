# Digests for Browser DevTools mastery (used in every phase)

These are the sources worth reading in full one day, each reduced to a ten-minute note. Read
them in this order.

1. [[ecma-426-source-map-browser-devtools-mastery|ECMA-426 Source Map standard]] — it defines the source map format (the `mappings` string and `ignoreList`) that every Sources-panel lesson depends on.
2. [[chrome-devtools-network-docs-browser-devtools-mastery|Chrome DevTools Network features reference]] — it defines the Network panel: each timing phase, throttling, initiators and HAR export.
3. [[chrome-devtools-memory-docs-browser-devtools-mastery|Chrome DevTools memory problems]] — it defines the leak workflow: watch memory grow, compare heap snapshots, read the Retainers.
4. [[firefox-devtools-user-docs-browser-devtools-mastery|Firefox DevTools user docs]] — it applies the same ideas in Firefox: grid, flex and font tools, and remote debugging through about:debugging.
